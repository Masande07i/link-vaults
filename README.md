# Project description
```Link Vault is a web application built with React, TypeScript, and Vite that enables users to save, organize, and manage their favourite websites in one place. Users can add links with a title, URL, description, and optional tags, as well as search, update, and delete saved links. The application uses Local Storage to persist data, ensuring that saved links remain available even after the browser is refreshed or closed. Designed with a clean, responsive interface, the project demonstrates core React concepts such as components, props, state management, hooks, array manipulation, and CRUD operations.```
